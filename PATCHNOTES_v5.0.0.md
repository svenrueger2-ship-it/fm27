# FUSSBALL MANAGER 2027 – Patch 5.0.0 „Hotseat, 4 neue Ligen & Deadline Day“

## 👥 Hotseat-Mehrspieler (offline, ein Gerät)
- Neue Karriere → Verein wählen → „Mehrspieler auf einem Gerät“: 2–4 Manager, jeder mit eigenem Verein (beliebige Liga).
- Jeder Manager hat alles eigen: Managerfigur, Karriere, Ruf, Stab, Posteingang, Scouting, Jugend, Kabine, Medien, Erfolge, Angebote.
- Ablauf pro Woche: Manager 1 bereitet vor und spielt sein Spiel → Übergabe-Bildschirm „Gerät weitergeben“ → Manager 2 … → dann läuft die Woche für alle.
- Direkte Duelle: Spielen zwei Manager gegeneinander, spielt der erste das Spiel, der Gegner sieht das Ergebnis bei seinem Zug.
- Übergabe-Bildschirm mit Manager-Duell-Tabelle und Ergebnissen der Woche; Managername oben in der Leiste.
- Die KI kauft menschlichen Vereinen keine Spieler weg und stellt ihre Aufstellung nicht um.
- Saisonende erst, wenn alle Ligen der Manager fertig sind; Saisonbilanz für jeden Manager.
- „Vorspulen“ ist im Hotseat-Modus aus.
- Getestet: komplette Saison mit 3 Managern (Bundesliga ×2, Schottland), 102 Züge, eigene Karrieren, keine KI-Verkäufe.

## ⏰ Deadline-Day-Liveticker
- Am letzten Tag eines Transferfensters: Knopf „Liveticker starten“ in der Zentrale.
- Uhr läuft von 9:00 bis 23:59, Wechsel, Gerüchte und Last-Minute-Angebote für deine Spieler laufen ein, große Deals als 🚨 BREAKING am Abend.
- Eine zusätzliche Runde KI-Transfers macht den Tag wirklich hektisch.
